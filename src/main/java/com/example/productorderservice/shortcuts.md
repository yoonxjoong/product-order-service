파일 생성
1. Cmd + 1 : 프로젝트 창(왼쪽 파일 트리) 포커스 이동
2. 원하는 폴더 이동
3. Cmd + N :  새 파일 추가

에디터 창에서 바로 파일 생성
- Ctrl + Option + N

변수 추출
- Cmd + Option + V

메서드 추출
- Cmd + Option + M

변수 인라인
- Cmd + option + N

Move 리팩토링 / 내부함수 상위 클래스로 분리
- F6



화면분할 탭 이동
- Option + Tab

최근탭 이동
- cmd + E

코딩용 블록
- Option + 위 방향키

리팩토링 단축키
-Control + T

빠른 수정(Quick Fix) 단축키
- Option + Enter

필드 생성 및 할당 (Quick Fix) 단축키
   대입하고 싶은 파라미터 이름(예: name, price, discountPolicy) 위에 커서를 둡니다.

macOS: Option + Enter

한 번에 모든 필드 할당하기 (Generate Menu)
   생성자나 메서드 내부에서 파라미터들을 클래스 필드와 한꺼번에 연결하고 싶을 때 사용하는 방법입니다:

macOS: Cmd + N -> Form Fields 또는 생성자/필드 관련 항목 선택

Windows / Linux: Alt + Insert

command + shift + o
